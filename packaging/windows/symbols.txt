Ánima debug symbols

anima.pdb and anima_cli.pdb are the debug symbols of anima.exe and
anima-cli.exe from the release with the same version and architecture as this zip. They
were written by the same build as those exes, so they match only them: a PDB from a local build
of the same commit doesn't.

They hold Ánima's function names (release builds carry no source line tables), which is
what a profiler needs to show where the time goes. Ánima doesn't need them to run.

To use them, either copy both files next to anima.exe (the installer's folder, by default
%LOCALAPPDATA%\Programs\Nodalia\Anima, or C:\Program Files\Nodalia\Anima when
installed for everyone), or add this folder to the profiler's symbol path:

  Windows Performance Analyzer: Trace > Configure Symbol Paths, add this folder, then
                                Trace > Load Symbols.
  Superluminal:                 Settings > Symbols, add this folder as a symbol location.
  Visual Studio:                Tools > Options > Debugging > Symbols, add this folder.
  Any tool reading _NT_SYMBOL_PATH: set _NT_SYMBOL_PATH to this folder.

When you share a profile in an Ánima issue, say which version and architecture you ran
(Help > About).
