Ánima 0.1.2 trae un punto de transformación que puedes mover, cajas que giran con el objeto, opacidad de capa y líneas limpias, y buscar actualizaciones ya no falla con «http status: 403».

*Ánima 0.1.2 brings a transformation point you can move, boxes that turn with the object, layer opacity and clean lines, and checking for updates no longer fails with "http status: 403".*

## Español

### Novedades

- **Punto de transformación:** con Transformación libre, arrastra el círculo blanco a donde el objeto debe girar. Se ajusta a las esquinas, los lados y el centro (Alt lo coloca libremente) y doble clic lo vuelve a centrar. Las instancias de símbolo lo guardan, y las interpolaciones lo usan.
- **La caja gira con el objeto:** un objeto seleccionado muestra su propia caja, girada, escalada e inclinada como está.
- **Opacidad de capa:** de 0 a 100 % en Propiedades de capa y en su menú contextual.
- **Capas más rápidas de manejar:** reordénalas arrastrando, y muestra, bloquea o pasa a contorno todas a la vez.
- **Formas:** Convertir líneas en rellenos, Expandir relleno y Suavizar bordes de relleno.
- **Cuentagotas**, y pegar una imagen copiada desde otras apps.
- **F6 y F7** actúan sobre los fotogramas seleccionados.
- **Líneas limpias:** cada línea se rellena como un solo contorno, sin bordes más oscuros donde se solapaban sus trozos, y las exportaciones SVG y HTML escriben un contorno limpio.
- Mejoras al importar archivos .fla.

### Correcciones

- Buscar actualizaciones ya no termina en «Could not reach GitHub Releases: http status: 403». GitHub solo responde unas pocas consultas por hora desde cada red, compartidas por todas las apps que la usan. Ahora Ánima guarda la última lista de versiones y, al volver a buscar, solo pregunta si ha cambiado, una pregunta que no gasta ese límite.
- Si el límite se agota igualmente, Ánima sigue sabiendo cuál es la versión más nueva y ofrece abrir su página. Si no puede saberlo, explica en tu idioma qué ha pasado y cuándo volver a intentarlo.
- Descargar una actualización ya no se corta a mitad (por ejemplo al 75 %) con «timeout: receive body». Solo se detiene si la conexión deja de responder, y al reintentar sigue desde donde iba.

## English

### What's new

- **Transformation point:** with Free Transform, drag the white circle to where the object should turn. It snaps to the box's corners, sides and centre (Alt places it freely), and double-clicking centres it again. Symbol instances keep it, and tweens use it.
- **The box turns with the object:** one selected object shows its own box, turned, scaled and skewed as it is.
- **Layer opacity:** 0 to 100 % in Layer Properties and in the layer's right-click menu.
- **Quicker layer handling:** reorder layers by dragging, and show, lock or outline all of them at once.
- **Shapes:** Convert Lines to Fills, Expand Fill and Soften Fill Edges.
- **Eyedropper**, and pasting a picture copied from other apps.
- **F6 and F7** act on the selected frames.
- **Clean lines:** every line is filled as one outline, with no darker edges where its pieces overlapped, and SVG and HTML exports write one clean outline.
- Fixes when importing .fla files.

### Fixes

- Checking for updates no longer ends in "Could not reach GitHub Releases: http status: 403". GitHub answers only a few requests an hour from each network, shared by every app on it. Ánima now keeps the last list of releases and, when it checks again, only asks whether it changed, a question that does not spend that limit.
- If the limit runs out anyway, Ánima still knows which version is newest and offers to open its page. If it cannot tell, it says in your language what happened and when to try again.
- Downloading an update no longer stops part way (at 75 %, say) with "timeout: receive body". It stops only if the connection stops responding, and a retry carries on from where it was.
